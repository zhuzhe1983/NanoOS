SET UP YOUR MODELS

先连接模型，
再开启更多可能。

在设备的「设置 → 应用设置 → 模型与服务」配置，
或使用设备自己的网页设置。这里是指南，不会保存配置。

  1. 01

    填写服务地址

    填设备能够访问的服务根地址。当前 LocalAI 接入由固件补全接口路径，不要重复填写 /v1，也不要使用电脑上的 localhost。

  2. 02

    确认服务认证方式

    本版尚未提供通用 API Key 输入，需使用设备可访问的免鉴权局域网服务或受控网关。不要把密钥拼在地址里；本站不收集 API Key。

  3. 03

    分别指定模型 ID

    填写服务端实际提供的识别、对话、朗读与文生图模型名称。模型 ID 区分大小写；不能仅凭展示名称推断。

  4. 04

    保存后，逐项验证

    先用短句测试识别，再测试对话与朗读，最后验证图像生成。缺少配置时隐藏对应入口的逻辑，随 0.0.1 一起验证。

这些 AI 功能现在都能用了吗？

还没有。已有文字问答、录音识别与回答朗读的开发实现；完整 PTT、缺配置隐藏入口及语音换墙纸正在开发与验证，通用 API Key 配置尚未提供。0.0.1 固件尚未发布，本页描述计划能力，不代表整条流程已在设备上验收。

一定要配置四个模型吗？

按所需能力配置即可：语音问答需要识别与对话模型；听回答可另配朗读模型；语音生成墙纸还需要图像模型。计划只呈现已配置的能力，具体依赖关系以发布版为准。

我说的话会发送到哪里？

语音识别、对话、语音合成和图像生成由你设置的服务处理，相应的录音或文字会在操作时发往该服务。请按服务的隐私与收费规则使用。本站只提供介绍，不接收录音、提示词或密钥。

能直接填写任意厂商的模型吗？

模型名称相同不代表接口兼容。当前实现以 LocalAI 兼容接口为基础，服务必须能被设备访问，并匹配固件支持的请求与返回格式；不承诺所有模型服务即填即用。
