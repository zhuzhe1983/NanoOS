面向首次使用者的功能与格式说明。
适用于 FAKE POD NANO PRO S31，不适用于 ESP32-S3。

MEDIA

音乐、视频与照片

本地歌曲信息、封面和真实音频频谱；视频播放、暂停与定位；JPEG、PNG 照片浏览。可在 WebUI 上传时转换格式。

VOICE

按住说，松手发送

松手后自动识别并提交，字幕只用于显示；录音时滑出可取消。生成墙纸先预览，确认后才应用。先到 AI 指南配置模型。

READ

读几页，再听几页

阅读文字书与导入的原页书籍。有可用正文时，可使用自然语音朗读，并为选定页范围准备离线缓存。日历、墙纸与录音历史也在手边。

WHAT’S UPDATED

r018 的音乐、书籍与视频。

设备负责浏览和播放。上传、整理和格式转换在浏览器中完成。

MUSIC

音乐与播放列表

按专辑、艺人浏览音乐，用首字母快速定位。在 WebUI 中可以把单曲或整张专辑加入播放列表，拖动调整曲序，也可以从 Emby 导入。

BOOKS

书籍与 OPDS

从 OPDS 浏览、搜索并选择书籍，或直接上传文件。调整设备字号后，按新的版面重新分页，继续阅读。

VIDEO

视频与格式转换

从 Emby 导入或上传本地视频。WebUI 检查播放兼容性，需要时在浏览器转换，再将成品写入 TF 卡。

表盘与 Badge，按你的方式展示。

表盘与锁屏
从「设置 → 应用设置 → 表盘」统一选择样式。带刻度的图集背景搭配指针；选择数字样式时会改用系统墙纸。锁屏向左滑进入表盘、向右滑进入 Badge，三页不循环；首次触摸只唤醒，仍使用音量组合键解锁。动态阴影只在解锁后的可见表盘预览中短时响应触摸，锁屏与息屏时停用。
先复制背景资源
下载 完整 TF 资源包 ↓，按包内说明把字库、表盘背景、墙纸和 WebUI 工具复制到 TF 卡；已有文件请先备份。也可只下载 表盘背景文件，保存为 TF 根目录下的 nanoos/faces/atlas-v1.nfa。资源单独存放，网页刷机不会写入 TF 卡；未安装或读取失败时使用系统背景。资源 SHA-256 校验 →
图片与静音视频
在照片或视频页面添加到 Badge，再管理顺序、启用状态和裁剪范围。移除 Badge 条目只移除引用，不删除媒体原文件。视频格式沿用下方限制，展示时静音；如开启 Badge 常亮，它仅在展示时生效，亮度上限为 50%，离开后恢复系统设置。
画面切换
Badge 先淡出旧画面，下一项首帧就绪后淡入；单张静态图片不重复解码。表盘加载增加遮挡与渐显，屏幕提交合并刷新区域。设备软件画面与有限实机观察确认了相关流程，不代表物理 LCD 零撕裂或恒定帧率。

第一次使用，从这里开始。

首页与设置
左右滑动切换应用，从顶部下滑打开控制中心；应用设置集中在「设置 → 应用设置」。准备设备可识别的 FAT32 存储卡及配套资源，按各应用要求放入文件。换入文件后，返回首页再打开应用刷新；可从控制中心返回正在播放的媒体。
连接模型服务
在「设置 → 应用设置 → 模型与服务」填写设备可访问的服务根地址与实际模型 ID。语音问答需 ASR 与 LLM，听回答另需 TTS，生成墙纸另需文生图。固件补全接口路径，不要重复填写 /v1。查看配置指南 →
认证与隐私
本版没有通用 API Key 输入框，使用免鉴权局域网服务或受控网关；不要把密钥写进地址。MyAI 设备绑定不是通用密钥接入。语音或文字由你配置的服务处理，本站不接收录音、提示词或密钥。

选对格式，用起来更顺手。

音乐
MP3、ADTS AAC-LC、整数 PCM WAV、FLAC；以单／双声道、8–48 kHz 为主。FLAC 最高 24 位，并有解码块大小限制。M4A、ALAC 没有直接的本地音乐播放路径，改后缀不能完成转换。
视频
支持 H.264 Baseline MP4、MJPEG AVI 和 MJPEG 视频流。WebUI 按最长边 460 像素、最高 24 fps 检查视频。片源不兼容时，上传窗口会准备转换工具并显示进度。转换期间请保持浏览器打开、设备联网。
文字书
UTF-8 TXT 可直接阅读。也可在 WebUI「书籍」中导入 EPUB 等格式，按可提取的正文和目录生成设备可以阅读的文件。
PDF 与图像书
上传 PDF 后，浏览器会提取页图和可用正文。只有图片时会先询问是否保存，保存后可在设备上翻页查看。有可用正文的书籍可以朗读。

提前准备，断网后继续听。

选定页范围
自然语音先连接已配置的 TTS 服务，每次预处理最多四页，不自动在后台生成整本书。下载并保留完整语音，不为凑页长裁切或变速。有效缓存可断网播放；正文、模型或服务变化可能需要重新准备。
64 MiB · 64 段
缓存最多 64 MiB、64 个完整片段。所选范围按正文和已有缓存保守预留空间，不能保证每页或每次四页都装得下。可按书清理缓存，不必清空其他书籍。缓存不等于将模型安装到设备，也不保证整本离线或跨页韵律连续。
取消与存储异常
正常取消会清理本次未完成的语音，保留已完成缓存。若存储错误导致索引残留状态不确定，会保留文件并提示检查，不保证所有错误都自动清理。

连接能力，仍有适用范围。

LocalSend
已修复 Mac 原生 LocalSend 使用分块传输时被拒绝的问题，完成一次 660,326 字节文件发送及 TF 卡完整读回校验。其他平台、客户端版本和文件组合仍需分别验证；普通单文件传输不会自动组装书籍目录。
AirPlay
保留 AirPlay 音频接收路径，兼容范围有限；不能保证所有原生 Apple 发送端均可使用。发送尚未实现，不提供视频镜像。
语音与演示
采用按住说话，不提供 VAD 自动检测或持续免按键对话。真实语音换墙纸视频尚未录制。查看演示状态 →
源码与许可
AirPlay 接收组件采用 GPL-3.0-or-later，并附有针对 Espressif 二进制组件的额外许可。完整对应源码的提供方式尚未解决；许可证和上游链接不能替代对应源码。测试版身份与未来重写计划不改变当前分发要求。查看许可与源码状态 →

网络恢复，有明确边界。

保护与手动操作
持续弱信号或短时间连续掉线会触发冷却，自动重试间隔从 30 秒逐步延长，最长 120 秒。原来保存的 Wi-Fi 开关和“一直打开”偏好不因此改变；手动关闭与 USB 模式优先。暂停设备联网时，已开启的设置热点可继续保留。
媒体恢复
仅默认列表中明确标记的直播电台会在网络恢复后最多重开两次。普通播客和未知类型链接不自动从头重播，精确断点续播仍需单独支持。缓冲与恢复期间保留已接受的暂停状态，等待可取消。
验证范围
阈值和退避已通过生产代码故障注入；实机已验证正常联网、手动关闭／重连及媒体暂停／继续流程。尚未在设备上人为衰减射频或复现弱网卡死，不能据此确认卡死根因。部分 SDK 内部慢速响应仍可能超过应用层期限，不保证所有请求均有严格的整体超时。

为其他设备铺路，当前仍面向 S31。

后台运行与界面
联网维护、Web 控制调度与后台朗读联网由独立系统任务推进，减少对界面刷新循环的依赖。需要建页、切换音频路由或解除锁屏的操作仍由前端协调。配置只有在相关模块和前端均确认后，才显示为完整应用成功。
显示适配
新增设备能力描述、刷新区域合并、提交节流和异步完成接口，并提供电子纸刷新策略准备。当前没有墨水屏驱动；实际移植还需面板驱动、像素转换、完整画面来源和页面布局适配。此固件不能直接刷入其他显示设备。
联网适配
通用连接接口区分链路、IP 地址与互联网可达性。S31 仍使用 Wi-Fi；取得 IP 地址不等于已确认互联网可用。蜂窝接口只做过模拟验证，没有接入真实 4G 模组，部分媒体、AI 与天气服务还需在移植时替换 Wi-Fi 专属逻辑。

解压后运行
把 ZIP 完整解压到本地较短路径，例如 C:\NanoOS，不要在压缩包内直接运行。双击 Flash-NanoOS.cmd：输入 1 或直接回车选择完整安装，输入 2 只安装 App；不确定区别时选完整安装。按提示核对设备和方式，输入 确认刷机 才开始。PowerShell 用法和更多选项见包内 README-zh-CN.txt。
另行复制 TF 资源
安装包内附有 TF-resources.zip。另行解压后，按其中说明把 nanoos 目录合并复制到 TF 卡，保留自己的文件。也可使用本页单独提供的 TF 资源包。刷机不会格式化 TF 卡，也不会自动写入字库、表盘或墙纸。
备份与恢复
Windows 工具的会话备份默认保存在 %LOCALAPPDATA%\NanoOS\FlashBackups\，恢复步骤见包内 README-zh-CN.txt；完整模式可在备份校验后迁移自制分区，输入“确认覆盖”才会替换布局。完整会话备份可用于恢复同一台设备。网页保存的是单个 16 MiB 镜像，不是 Windows 工具的会话备份目录，不能直接作为 RestoreFrom 目录使用；网页没有回退按钮。如需恢复网页备份，或工具拒绝自动恢复，请保留备份并交由熟悉设备布局的人员处理。
