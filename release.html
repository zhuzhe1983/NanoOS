MEDIA

音乐、视频与照片

本地歌曲信息、封面和真实音频频谱；视频播放、暂停与定位；JPEG、PNG 照片浏览。复杂媒体需要先在电脑转换。

VOICE

按住说，松手发送

松手后自动识别并提交，字幕只用于显示；录音时滑出可取消。生成墙纸先预览，确认后才应用。先到 AI 指南配置模型。

READ

读几页，再听几页

阅读文字书与导入的原页书籍。有可用正文时，可使用自然语音朗读，并为选定页范围准备离线缓存。日历、墙纸与录音历史也在手边。

第一次使用，从这里开始。

首页与设置
左右滑动切换应用，从顶部下滑打开控制中心；应用设置集中在「设置 → 应用设置」。准备设备可识别的 FAT32 存储卡及配套资源，按各应用要求放入文件。换入文件后，返回首页再打开应用刷新；后台播放设置决定离开应用后是否继续播放。
连接模型服务
在「设置 → 应用设置 → 模型与服务」填写设备可访问的服务根地址与实际模型 ID。语音问答需 ASR 与 LLM，听回答另需 TTS，生成墙纸另需文生图。固件补全接口路径，不要重复填写 /v1。查看配置指南 →
认证与隐私
本版没有通用 API Key 输入框，使用免鉴权局域网服务或受控网关；不要把密钥写进地址。MyAI 设备绑定不是通用密钥接入。语音或文字由你配置的服务处理，本站不接收录音、提示词或密钥。

选对格式，用起来更顺手。

音乐
MP3、ADTS AAC-LC、整数 PCM WAV、FLAC；以单／双声道、8–48 kHz 为主。FLAC 最高 24 位，并有解码块大小限制。M4A、ALAC 没有直接的本地音乐播放路径，改后缀不能完成转换。
视频
MP4 中的 H.264 Constrained Baseline，Level ≤ 3.1，逐行、最高 320×240、输入帧率 ≤ 24 fps、最多两参考帧，单段时长不超过一小时。音轨可用 AAC-LC，最高 48 kHz、单／双声道。输入上限不代表 LCD 能持续显示 24 fps。HEVC、AV1、VP9、MKV 及 H.264 Main／High 等片源需先在电脑转换，保留完整内容与自然速度，不截短、不做时间拉伸；长度不匹配时调整画面。
文字书
UTF-8 TXT 可直接阅读，正文上限 16 MiB。EPUB、DOCX 等需在电脑提取正文与目录后导入，不保留全部复杂排版，也不绕过 DRM。设备不直接解压 EPUB；仅改名或拷入原文件不能代替导入。
PDF 与图像书
PDF、XTC／XTCH 需在电脑生成原页书籍包并完整复制，保留页图与页序。设备不解析原始 PDF 或运行 OCR；普通单文件收件箱不会自动组装书籍目录。文字层应检查提取顺序；扫描页需要 OCR 并复核。无可用或待复核文字时可以看图，不能自然朗读。不保证任意扫描书、整本 PDF 的朗读与音质均已验证。

提前准备，断网后继续听。

选定页范围
自然语音先连接已配置的 TTS 服务，每次预处理最多四页，不自动在后台生成整本书。下载并保留完整语音，不为凑页长裁切或变速。有效缓存可断网播放；正文、模型或服务变化可能需要重新准备。
64 MiB · 64 段
缓存最多 64 MiB、64 个完整片段。所选范围按正文和已有缓存保守预留空间，不能保证每页或每次四页都装得下。可按书清理缓存，不必清空其他书籍。缓存不等于将模型安装到设备，也不保证整本离线或跨页韵律连续。
取消与存储异常
正常取消会清理本次未完成的语音，保留已完成缓存。若存储错误导致索引残留状态不确定，会保留文件并提示检查，不保证所有错误都自动清理。

连接能力，仍有适用范围。

LocalSend
保留实验性传输能力，官方 LocalSend 图形客户端互通尚未完成，不应作为已保证兼容的导入方式。
AirPlay
保留 AirPlay 音频接收路径，兼容范围有限；不能保证所有原生 Apple 发送端均可使用。发送尚未实现，不提供视频镜像。
语音与演示
采用按住说话，不提供 VAD 自动检测或持续免按键对话。真实语音换墙纸视频尚未录制。查看演示状态 →
源码与许可
AirPlay 接收组件采用 GPL-3.0-or-later，并附有针对 Espressif 二进制组件的额外许可。完整对应源码的提供方式尚未解决；许可证和上游链接不能替代对应源码。测试版身份与未来重写计划不改变当前分发要求。查看许可与源码状态 →
网页安装
已在桌面 Chrome 与 S31 实机完成应用写入、完整 SHA-256 读回和保护区校验。安装时保持页面在前台，不要锁屏、休眠或关闭页面；隐藏页面与后台运行尚未验证。每次安装后仍需确认设备正常启动。
INSTALL NANOOS

准备好，再写入。

只面向保留原分区表的 S31 设备。安装器将核对镜像、芯片和分区，只更新现有 app0，并完整读回校验。

不会执行全盘擦除。中途停止可能使 app0 不完整；现有启动选择保持不变，写入成功仍需确认设备能正常启动。
